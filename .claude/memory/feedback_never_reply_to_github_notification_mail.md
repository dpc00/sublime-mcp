Replies to emails from notifications@github.com go to a hidden `reply+...@reply.github.com` address and GitHub publishes them as public comments (shown "via email"). Donald replied that way to facelessuser (QuickCal#10, several times, including private details about his health, money and bandwidth) and earlier to braver/kaste on package_control_channel#9554; he never meant any of it to be public and had to delete the comments by hand on 2026-10-03.

**Why:** he intends an email reply to be seen only by the person who wrote to him. A public comment can hurt him (it did) and cannot be recalled from subscribers' inboxes.

**How to apply:**
- Never reply to, forward to, or draft a Gmail reply addressed to a notifications@github.com thread or to any `reply+...@reply.github.com` address.
- When a GitHub notification needs an answer, write the draft text for him (in a Sublime tab or the chat), say plainly that it would be public if posted, and let him decide where it goes. A private reply is only possible if the person publishes an email address on their GitHub profile: look it up, put the draft in Gmail Drafts addressed to that address, and he sends it.
- Offered (not yet approved by him): turn off GitHub email notifications for dpc00 so there is nothing to reply to. If he later says yes, do it in GitHub Settings > Notifications.
