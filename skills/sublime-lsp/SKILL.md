## The one reusable bridge (read directly from lsp_mcp.py; this is real,
## non-obvious synchronization, not something to improvise from scratch)

```python
import sys, threading

def get_active_session_for_view(view, config_name=None):
    reg = sys.modules.get("LSP.plugin.core.registry")
    if not reg:
        return None
    wm = reg.windows.lookup(view.window() or sublime.active_window())
    if not wm:
        return None
    sessions = list(wm.get_sessions())  # this is a GENERATOR -- list() it, don't index/subscript directly
    for session in sessions:
        if config_name and session.config.name != config_name:
            continue
        try:
            # current signature: can_handle(view, scheme, capability, inside_workspace)
            if session.can_handle(view, "file", None, True):
                return session
        except TypeError:
            # older signature: can_handle(view) -- fall back for older LSP core versions
            if session.can_handle(view):
                return session
    return next((s for s in sessions if not config_name or s.config.name == config_name), None)

def execute_lsp_request(view, method, params, timeout=8.0):
    """Call this from a background thread, e.g. inside eval_python spawn a
    threading.Thread and poll a file/global for the result -- eval_python's
    own tool call has a hard ~5s ceiling and event.wait() blocking THAT
    thread will just time out the tool call itself, not the LSP request."""
    session = get_active_session_for_view(view)
    if not session:
        return {"error": "No active LSP session for this file."}
    proto = sys.modules.get("LSP.plugin.core.protocol")
    req = proto.Request(method, params)
    event = threading.Event()
    result, err = [], []
    session.send_request_async(req, lambda r: (result.append(r), event.set()),
                                     lambda e: (err.append(e), event.set()))
    if not event.wait(timeout):
        return {"error": "LSP request timed out after {}s".format(timeout)}
    return {"result": result[0]} if result else {"error": str(err[0]) if err else "unknown"}
```

## Standard LSP method names (call execute_lsp_request(view, method, params))

| Method | Params (beyond textDocument/position) | Gets you |
|---|---|---|
| `textDocument/hover` | — | hover info |
| `textDocument/definition` | — | go to definition |
| `textDocument/typeDefinition` | — | go to type definition |
| `textDocument/declaration` | — | go to declaration |
| `textDocument/implementation` | — | go to implementation |
| `textDocument/references` | `context: {includeDeclaration: bool}` | find references |
| `textDocument/rename` | `newName: str` | rename symbol |
| `textDocument/completion` | — | completions at position |
| `textDocument/signatureHelp` | — | signature help |
| `textDocument/codeAction` | `range`, `context: {diagnostics}` | code actions |
| `textDocument/formatting` | `options: {tabSize, insertSpaces}` | format document |
| `textDocument/foldingRange` | (no position needed) | folding ranges |
| `textDocument/documentLink` | (no position needed) | document links |
| `textDocument/codeLens` | (no position needed) | code lenses |
| `textDocument/inlayHint` | `range` | inlay hints |
| `workspace/symbol` | `query: str` (no textDocument/position) | search workspace symbols |

`position: {"line": N, "character": N}` (0-based, unlike sublime-mcp's own
1-based line/col tools -- subtract 1 when converting a Sublime cursor).

## Diagnostics and sessions (not via execute_lsp_request -- read directly
## off the registry/session objects, no request round-trip needed)

```python
reg = sys.modules.get("LSP.plugin.core.registry")
wm = reg.windows.lookup(view.window())
session = list(wm.get_sessions())[0]        # session.config.name, e.g. "LSP-pyright"
                                             # (not bare "pyright" -- verified name includes the LSP- prefix)
sv = list(session._session_views)[0]        # one SessionView per (session, view) pair
sb = sv.session_buffer
sb.diagnostics                              # list of (dict, sublime.Region) tuples, no request needed
# each dict: {"range": {...}, "message": ..., "severity": 1-4, "source": "Pyright", "code": ...}
```

this path needs no request/response round-trip at all, unlike hover/definition/etc.

## Gotchas

- Session `config.name` is the LSP client package's own name (e.g.
  `"LSP-pyright"`), not the underlying language server's name (`"pyright"`) --
  don't filter on the bare tool name.
- `wm.get_sessions()` returns a **generator**, not a list/tuple -- `list()`
  it before indexing or it raises `'generator' object is not subscriptable`.
- LSP's async model is **callback-based** (`send_request_async(req, on_result, on_error)`),
  not coroutine-based like Debugger's `core.run()` -- the `threading.Event`
  bridge above is the correct, tested way to get a synchronous result;
  don't assume `core.run()`-style bridging applies here.
- `workspace/symbol` and the no-position methods (`foldingRange`,
  `documentLink`, `codeLens`) don't take a `position` in params -- only
  `textDocument`.
- A view opened just to query it (`get_or_open_view_for_file` in
  lsp_mcp.py uses `sublime.TRANSIENT`) may not have an LSP session attached
  yet if the language server takes a moment to initialize -- if
  `get_active_session_for_view` returns None right after opening a file,
  wait briefly and retry rather than treating it as "no LSP available."
